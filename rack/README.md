# Rack

8 in. custom-width minirack, 12U tall, built from 20 × 20 aluminum extrusion.

## Frame

| | |
|---|---|
| External size (W × D × H) | 206 × 350 × 589 mm |
| Usable height | 533.4 mm, 12U (1U = 1.75 in = 44.45 mm) |
| Clear width between uprights | 166 mm |
| Mounting hole pitch | 186 mm, EIA-310 vertical spacing |
| Panel width | 203.2 mm (8 in.) |
| Profile | 20 × 20, 6 mm slot, 6063-T5 |
| Corners | 3-way corner connectors, adding 5 mm at each upright end, plus L brackets (see Hardware) |
| Tray mounting | M5 drop-in T-nuts in the front slot |
| Sides | acrylic panels, air flow from U12 (intake) to U1 (exhaust) |

## Hardware

| Item | Qty | In stock | To buy |
|---|---|---|---|
| 3-way corner connector | 8 | 4 | 4 |
| L corner bracket, 2 holes | 32 | 16 | 16 |
| M5 hammer nut, 20 series | 64 | 8 | 56 |
| M5 × 8 button head hex screw, silver | 64 | 0 | 64 |

L brackets go on every upright to rail joint of the sides and the back: 2 at each back vertex,
2 at each intermediate joint on the front uprights and 4 at each intermediate joint on the back
uprights. The four front vertices take none, so the front stays clear for the rack panels.
Each bracket takes two hammer nuts and two screws.
